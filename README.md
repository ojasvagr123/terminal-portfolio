# Ojasv Agrawal - Portfolio

A responsive, company-ready portfolio built with Next.js and TypeScript. It presents Ojasv's engineering work across full-stack development, applied AI, cybersecurity and financial infrastructure.

## Highlights

- Four deployed project case studies with source links
- Internship and research experience timeline
- Education, leadership, technical skills and achievements
- Downloadable resume and direct contact links
- Responsive, accessible layout with reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```

## Stack

Next.js 16, React 19, TypeScript, CSS and Lucide icons.
